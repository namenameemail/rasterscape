# 03. Жесты volume на таче

## Сейчас

Volume: орбита — ПКМ/СКМ, zoom — колесо. На телефоне этого нет. Рисование после [01](01-canvas-touch.md) заберёт один палец под кисть.

## Сделать

1. Орбита камеры volume одним понятным жестом (например один палец + удержание второй зоны / два пальца drag — выбрать один вариант и зафиксировать в задаче при реализации).
2. Zoom volume (pinch или аналог колеса).
3. Не отбирать у кисти обычный один палец для рисования поверх volume.

## Готово когда

На телефоне при включённом volume можно и рисовать одним пальцем, и отдельно поворачивать / приближать объём.
