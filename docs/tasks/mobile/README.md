# Мобильные телефоны

На телефоне **не рисуется** по канвасу паттерна: палец не запускает кисть/линию. Плюс десктопный лэйаут (fixed-панель 210px, hover, мелкие кнопки) на узком экране мешает даже когда touch заработает.

## Почему рисование молчит

Рисование паттерна идёт через [`CanvasEventsService`](../../../src/store/patterns/_service/patternServices/CanvasEventsService/index.ts): только мышь. `touch*` закомментированы. Старый [`Canvas`](../../../src/components/_shared/Canvas/index.tsx) touch умеет — паттерн через него не идёт.

## Цель блока

С телефона: **рисовать**, **достать настройки**, **не воевать со скроллом**, базово крутить **volume**.

Не цель: отдельное мобильное приложение или полный редизайн всех панелей.

## Целевой вид (кратко)

- Канвас на почти весь экран.
- Настройки паттерна (`pattern-left`) — bottom sheet по кнопке.
- Инструменты — компактная полоса.
- Режим включается классом вроде `layout-mobile` по ширине / coarse pointer (не по UA).

Подробности и шаги A→D — в [02](02-scroll-and-chrome.md).
