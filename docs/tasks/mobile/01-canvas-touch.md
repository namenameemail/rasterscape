# 01. Touch: рисование по канвасу паттерна

## Сейчас

На телефоне палец по канвасу паттерна **ничего не рисует**.

События рисунка собирает `CanvasEventsService`: только мышь (`mousedown` / `move` / `mouseup`). Строки с `touchstart` / `touchmove` / `touchend` закомментированы. Координаты и `buttons` заточены под `MouseEvent`.

Старый `components/_shared/Canvas` touch слушает — можно подсмотреть перевод touch → те же хендлеры.

## Сделать

1. На мониторе паттерна (и маски, тем же сервисом) принимать палец: start / move / end.
2. Координаты как у мыши (`offsetX` / `offsetY` или эквивалент от `pageX` + offset канваса) — чтобы кисть и линия работали без правок инструментов.
3. Во время штриха не скроллить страницу (`preventDefault` на touchmove жеста).
4. Мультитач в первой версии не обязателен: достаточно одного пальца (как одна мышь).
5. Проверить: кисть, линия, маска; после отпускания штрих остаётся.

Предпочтительно **Pointer Events** (`pointerdown` / `pointermove` / `pointerup` + `setPointerCapture`), если хватает поддержки: один код для мыши и пальца. Иначе — явный touch рядом с mouse, по образцу старого `Canvas`.

## Готово когда

С телефона (или эмулятора touch) можно провести линию/кисть по канвасу паттерна так же, как мышью на десктопе. Мышь при этом не ломается.
