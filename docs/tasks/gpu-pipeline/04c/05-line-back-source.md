# 4c.05 — линия «фон»: откуда берётся узор

Словарь: [`../names.md`](../names.md). UI: линия «фон» (`ELineType.SolidPattern`, в EN back).

Сама линия остаётся на 2D-холсте размера картинки. Это решение в [`../done/04c-04-helper-layer.md`](../done/04c-04-helper-layer.md): форма штриха из Canvas, на GPU её не подменяем.

Здесь другое. Внутри линии лежит картинка **другого** паттерна. Её каждый кадр жеста снимают на процессор, хотя сама картинка уже может жить на видеокарте.

## Как сейчас

1. `updateMaskedIfNeeded(true)` у паттерна-узора. Если у него видео или маска, это часто `ensureCpu`: скачать всю картинку.
2. Из этого холста `.masked` делают `createPattern` и им обводят линию.
3. Готовый штрих заливают в текстуру, как у обычной линии.

Файл: [`lineSolidPattern.tsx`](../../../../src/store/patterns/_service/patternServices/CanvasEventsService/ToolsServices/lineSolidPattern.tsx). Снимок узора: `PatternValuesService.masked`. На видеокарте тот же узор уже умеет собираться без скачивания: `ensureMaskedGpu`.

Опция «по центру мыши» (`patternMouseCentered`) сдвигает узор за курсором. Вид должен остаться тем же.

## Что сделать

Узор для обводки брать с текстуры, не скачивать весь source на каждый кадр жеста.

Готовый штрих по-прежнему можно рисовать через `stroke()` и `createPattern`. Меняется только откуда берётся картинка узора: не полный CPU-снимок, если текстура уже есть.

## Готово когда

Линия «фон» по паттерну с живым видео, с центром на мыши и без:

- линия выглядит как сейчас;
- в профиле нет регулярного `downloadGpu` **у паттерна-узора** только потому, что им обводят линию.

Общий CPU-снимок `.masked` для превью и прочего — отдельно, [08](08-values-masked.md).
