# 4c.11 — показ на монитор (`present`)

Сейчас: `presentGl` — blit в default FB + `drawImage` GL-канваса в monitor. На каждом кадре видео и после GPU-штриха. В 4b present Σ часто сопоставим с бывшим download.

## Сделать

Удешевить, если профиль показывает узкое место (реже копировать, другой путь на экран, не дублировать зря).

## Где

- `PatternBuffer.presentGl` / `present`
- baselines 4b present

## Готово когда

Frame Rec: `canvas.present` заметно дешевле или реже при том же виде; без регрессии видео.

## Сначала

Снять профиль «только видео, без жеста» и «жест + видео» — решить, стоит ли трогать.
