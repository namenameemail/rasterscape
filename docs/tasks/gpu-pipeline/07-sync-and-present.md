# Этап 7 — один смысл «где свежая картинка» и один present

Словарь: [`names.md`](names.md). Код: [`PatternBuffer.ts`](../../../src/store/patterns/_service/patternServices/PatternBuffer.ts), [`PatternToolService.ts`](../../../src/store/patterns/_service/patternServices/PatternToolService.ts).

Не про скорость present ([4c.11](done/04c-11-present.md) уже ок). Про то, чтобы флаги и ветки показа не ломались при правках.

## Сейчас

В буфере три независимых флага:

- `gpuInSync` / `cpuInSync` — где свежая картинка
- `gpuFromCanvas` (`textureFromCanvas`) — как перевёрнута текстура (из 2D-канваса или уже «как GL»)

Их выставляют почти все методы буфера (`stampGpu`, `compositeVideo`, `ensureGpu`, `ensureCpu`, …). Снаружи ещё `stampFlipY` у masked/selected и `drewGpu` у инструментов.

Показ после жеста — три ветки в `presentToolResult`:

1. инструмент сказал `drewGpu` → `presentGl`
2. иначе `isGpuAhead` → `presentGl`
3. иначе заливка с CPU (`presentFromCpu`)

Ошибка в одном флаге → зеркало на экране, кривой blend, или stale CPU поверх свежего GPU.

## Что улучшить

1. **Один контракт у буфера**  
   После любой записи пикселей состояние должно следовать из операции, а не из ручного набора трёх присваиваний в каждом методе. Например: «записали на GPU» → GPU свежий, CPU устарел, ориентация текстуры = GL; «залили с канваса» → оба свежие, ориентация = из канваса; «сняли на CPU» → CPU свежий, ориентация не трогаем. Внутренние хелперы ок; снаружи не трогать флаги по отдельности.

2. **Ориентация текстуры живёт в буфере**  
   Кому нужна текстура паттерна — спрашивает буфер (`textureFromCanvas` / `stampFlipY`), а не угадывает и не прокидывает `!textureFromCanvas` мимо. Инструменты не хранят свой flip отдельно от dest/source буфера.

3. **Один вход показа**  
   `presentToolResult` / monitor: буфер сам знает, показывать с GPU или с CPU. Флаг `drewGpu` у инструментов убрать (или оставить только как «я трогал пиксели», без выбора пути present). Нет трёх конкурирующих веток с одним смыслом.

## Когда готово

- Present после жеста и на кадре видео идёт через один путь; `drewGpu` не выбирает ветку.
- Смена sync/flipY только через операции буфера (нет «ручных» троек флагов в куче мест без общего правила).
- Ручная проверка без зеркала и без «старого кадра поверх»: видео; кисть pattern; линия «фон»; рисование в маску; жест при `isGpuAhead` + отпускание мыши.
- FPS / Present не цель; регрессия по Rec ок, если не хуже заметно.

## Не входит

Общий scratch GL, video+draw в один dest, кэш `ensureMaskedGpu`, платформер, undo/сейв.
