# Масштаб source: nearest / smooth

## Идея

При рисовании штампом или линией «фон» source можно увеличивать (`patternSize` и т.п.). Сейчас всегда резкие пиксели (`NEAREST`).

Нужен переключатель двух режимов:

- **nearest** — резкие границы между цветами, «лесенка» пикселей
- **smooth** — мягкое растягивание (linear), как было раньше

Где именно в UI (кисть / линия / общий параметр) — решим отдельно.

## Прикидка

**Что есть:** GPU-штамп и линия «фон» семплят source с `NEAREST` (`stamp.ts`, `patternFill.ts`); CPU-пути с `imageSmoothingEnabled = false`.

**Что сделать:**

1. Параметр режима (enum или bool) в нужном куске стейта + контрол в UI.
2. Прокинуть в stamp / patternFill / CPU `drawImage`: `NEAREST`↔`LINEAR`, `imageSmoothingEnabled` true/false.
3. Не трогать фильтры текстур dest/видео — только семпл source при штампе.

**Сложность:** небольшая, когда решим место в UI. Технически точки уже известны.

**Открытые вопросы:** один общий тумблер на все tool pattern или отдельно кисть / линия / select? Дефолт nearest или smooth?
