# Кисть | выдел-е: заморозить штамп

## Идея

В кисти «выдел-е» (`EBrushType.Select`) добавить переключатель.

Сейчас: штамп берётся из текущего куска картинки под выделением. Если рисуешь поверх этого же места, то чем рисуешь — тоже меняется.

Нужно: включил параметр — кусок «замораживается». Дальше кисть штампует всё ту же старую картинку и не может её переписать. Выключил — снова как сейчас, живой снимок.

## Прикидка

**Что есть:** `ensureSelectedGpu` каждый раз собирает штамп из dest + маски выделения. Параметры кисти — `BrushSelectParams` (size, opacity, composite).

**Что сделать:**

1. Параметр в `BrushSelectParams` + тумблер в UI кисти.
2. При включении (или на старте жеста при включённом) сохранить снимок штампа и больше не обновлять его из dest, пока параметр включён / пока не сменилось выделение.
3. GPU-путь: отдельная «замороженная» текстура; CPU-fallback — то же для `.selected`.

**Сложность:** небольшая–средняя. Логика штампа уже есть; главное — когда обновлять снимок и не забыть сброс при смене выделения или выключении параметра.

**Открытые вопросы:** заморозка на весь сеанс параметра или только на один жест? Сбрасывать ли при правке выделения?
