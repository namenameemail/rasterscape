# Кисть | shape: квадрат и паттерн

## Идея

У кисти shape (`EBrushType.Shape`) сейчас только круг. Нужны ещё типы формы:

1. **Квадрат** — штамп квадратом того же размера/цвета/прозрачности.
2. **Паттерн** — выбираешь паттерн; штампуешь его **форму** (с учётом маски), заливая **рандомным цветом**. Не картинку паттерна как у кисти pattern, а силуэт.

## Прикидка

**Что есть:**

- В типах уже лежит `EBrushShapeType` с `Circle` и `Square`, в UI и в draw используется только круг (`brushForm.tsx` → `stampCircles`).
- Кисть pattern уже умеет выбирать `patternId` — UI выбора паттерна можно переиспользовать.
- Маска паттерна есть (`maskService` / masked-буфер).

**Квадрат**

- Расширить GPU-штамп: сейчас шейдер круга; нужен квадрат (новый шейдер или общий «форма»).
- Курсор и параметры размера — почти те же.
- **Сложность:** небольшая. Enum уже намекает на Square.

**Паттерн как форма**

- Новый `EBrushShapeType` (например Pattern) + `patternId` в параметрах shape.
- На штамп: альфа/маска выбранного паттерна как силуэт, цвет — случайный на каждый штамп (или на жест — уточнить).
- Похоже на штамп с маской + solid color, не на полный `brushPattern`.
- **Сложность:** средняя. Нужны UI выбора паттерна, GPU-путь «маска → цвет», курсор, поведение при смене/удалении паттерна.

**Открытые вопросы:** цвет рандомный на каждый отпечаток или один на жест? Масштаб паттерна-формы — как `size` у круга или как у кисти pattern? Учитывать ли только mask-слой или ещё прозрачность самой картинки?
