# Видео: объём 3D-текстуры (raymarch + орбита)

Было идеей в [`../backlog/`](../backlog/README.md). Вынесено в блок.

Видео копит кадры в `TEXTURE_3D`. Режим volume view: **raymarch** + камера на **орбите**, toggle в панели видео. Кадр идёт в dest как обычное видео (`compositeVideo` — **затирает**). Мышь крутит камеру, не рисует.

## Уже решено

- Орбита + raymarch (не меш граней).
- Toggle → основной канвас паттерна; пишет в buffer как видео.
- Инкапсуляция: модуль `VideoVolumeView`; `ShaderVideoModule` владеет кубом; в `onFrame` одна развилка источника кадра; gate мыши в одном месте.
- Cut FXY / DEPTH + offsets; камера по умолчанию со стороны нового кадра.
