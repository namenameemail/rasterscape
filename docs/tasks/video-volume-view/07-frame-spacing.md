# 07. Плоские кадры и зазор

## Сейчас

Стек в volume — плотный куб по Z: кадры без видимых промежутков, сбоку артефакты марша.

## Сделать

1. Рисовать стек как **плоскости кадров** с пустыми зазорами (ray–plane, не dense march).
2. По умолчанию глубина стека = ширина текстуры (`volumeSpacing = 1`).
3. Слайдер **зазор** (`volumeSpacing`) — меняет расстояние между кадрами.

## Готово когда

- Сбоку видны отдельные кадры и промежутки.
- Слайдер меняет зазор; cut/ghost работают на плоскостях.
