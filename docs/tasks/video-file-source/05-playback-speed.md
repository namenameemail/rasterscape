# 05 — скорость воспроизведения

Зависит от [02](done/02-play-vs-update.md). Может идти параллельно с [03](done/03-timeline-ui.md) / [04](done/04-loop-range.md).

## Сейчас

Файл играет с обычной скоростью браузера. Менять скорость нельзя.

## Сделать

Ползунок или пресеты скорости (например 0.25…2×) → `playbackRate` у видеофайла. На scrub и update паттерна не ломать: скорость только про play файла.

## Готово

Скорость меняется, play файла её уважает.
