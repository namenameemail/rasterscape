# Видео: источник «файл»

Было идеей в [`../backlog/`](../backlog/README.md). Вынесено в блок.

Третий источник кадров рядом с **камера** и **паттерн** — **файл** с компьютера. Кадры идут в стек видео тем же путём. Проигрывание файла **отдельно** от «обновлять паттерн».

## Словарь

| В UI / тексте | В коде (ориентир) |
|---------------|-------------------|
| источник «файл» | `VideoSourceType.File` |
| обновлять паттерн | `updatingOn` |
| play / пауза файла | отдельно от камеры и от `updatingOn` |
| таймлайн | составной UI: позиция, scrub, участок цикла |
| участок цикла | loop in/out на таймлайне |
| скорость | `playbackRate` у `<video>` |
| миниатюра | превью загруженного файла |

## Уже решено (замысел)

- Play файла ≠ update паттерна: пауза файла + update → статичный кадр; scrub → кадр в паттерн; play без update → файл крутится «вхолостую».
- Таймлайн — отдельный составной компонент, не размазанный по панели видео.
