# 04 — участок цикла на таймлайне

**Статус: закрыт** (2026-09-26).

Зависит от [03](03-timeline-ui.md).

## Сейчас

После [02](02-play-vs-update.md) / [03](03-timeline-ui.md) loop всего файла и scrub есть. Выбрать фрагмент для цикла нельзя.

## Сделать

1. На том же таймлайне ([03](03-timeline-ui.md)) — выбор **участка** (начало / конец цикла).
2. Play файла крутит только этот участок; выход за край → прыжок на начало участка.
3. Понятный дефолт: участок = весь файл, пока пользователь не сузил.

## Сделано

- `fileLoopIn` / `fileLoopOut` (0…1); на таймлайне ручки in/out + подсветка участка.
- `VideoFileSource`: свой loop по участку (`timeupdate` + `enforceLoop`); нативный `loop` выключен.
- Новый файл сбрасывает участок на весь ролик.

## Готово

На таймлайне видно и двигается in/out; воспроизведение зациклено по участку.
