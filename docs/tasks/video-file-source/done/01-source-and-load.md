# 01 — тип File и загрузка файла

**Статус: закрыт** (2026-09-26).

## Сейчас

Источник видео — только **камера** и **паттерн** (`VideoSourceType`). Файла нет: с компьютера видео не подгрузить.

## Сделать

1. Добавить источник **файл** в выбор рядом с камерой и паттерном.
2. Кнопка / поле выбора видеофайла с диска пользователя.
3. Держать `<video>` (или тот же механизм, что у камеры) и отдавать **текущий кадр** в тот же путь «кадр → текстура → стек», что камера.
4. Пока без обязательного play: достаточно загрузить и иметь кадр (хотя бы первый / на паузе).

Play/pause и независимость от update — в [02](02-play-vs-update.md). Таймлайн — в [03](03-timeline-ui.md).

## Сделано

- `VideoSourceType.File` + `sourceFileName` в params.
- `VideoFileSource`: object URL, `<video>` на паузе после первого кадра; `pushSourceFrame` как у камеры.
- UI: выбор источника «файл» + picker (`accept=video/*`); update недоступен без файла.

## Готово

В панели можно выбрать «файл», указать видео, и при update паттерна в стек попадает кадр из этого файла.
