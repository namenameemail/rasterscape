# 03 — таймлайн: составной UI и scrub

**Статус: закрыт** (2026-09-26).

Зависит от [02](02-play-vs-update.md).

## Сейчас

Позицию в файле не видно и не двигать вручную. Нет отдельного UI для времени.

## Сделать

1. **Составной компонент** таймлайна (отдельный файл/модуль UI, не куча кнопок внутри `VideoControls`).
2. Показывает длительность и текущую позицию; **scrub** (потянул — `seek` на это время).
3. После seek текущий кадр файла обновляется: при update паттерна в стек уходит кадр с этой позиции (в т.ч. если файл на паузе).

Участок цикла на этом же таймлайне — в [04](04-loop-range.md); здесь достаточно позиции и scrub.

## Сделано

- [`VideoTimeline`](../../../../src/components/Pattern/VideoControls/VideoTimeline/index.tsx): позиция + длительность, scrub по треку → `setSourceFileCurrentTime`.
- В панели видео под источником «файл»; rAF синхронизирует время во время play.

## Готово

Есть таймлайн-компонент; двигаешь ползунок — в паттерн попадает соответствующий кадр.
