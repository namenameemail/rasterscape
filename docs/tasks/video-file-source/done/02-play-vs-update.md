# 02 — play файла отдельно от update паттерна

**Статус: закрыт** (2026-09-26).

Зависит от [01](01-source-and-load.md).

## Сейчас

После [01](01-source-and-load.md) файл загружен, кадр можно взять. Нет явного play/pause файла, отделённого от «обновлять паттерн». Loop, скорее всего, ещё нет или завязан неверно.

## Сделать

1. Play / пауза **файла** — свой тумблер (не путать с камерой и не с `updatingOn`).
2. Loop **всего** файла, пока нет участка ([04](04-loop-range.md)).
3. Пауза файла + включённый update → в паттерн каждый раз уходит **один и тот же** текущий кадр.
4. Play файла при выключенном update → файл крутится, стек паттерна не растёт, пока update снова не включат.

Scrub по времени — в [03](03-timeline-ui.md); здесь достаточно API: play/pause, текущая позиция, «отдать кадр сейчас».

## Сделано

- `filePlaying` + play/pause тумблер рядом с выбором файла.
- `VideoFileSource.play/pause`, `loop` всего файла; `currentTime` / `duration` / `setCurrentTime` для [03](03-timeline-ui.md).
- Play файла не трогает `updatingOn`: браузер крутит `<video>` сам; update только читает текущий кадр.

## Готово

Можно остановить файл и продолжать обновлять паттерн статичным кадром; можно крутить файл без update.
