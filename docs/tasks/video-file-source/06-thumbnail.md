# 06 — миниатюра предпросмотра файла

Зависит от [01](done/01-source-and-load.md). Удобнее после [03](done/03-timeline-ui.md), чтобы превью жило рядом с таймлайном.

## Сейчас

После загрузки файла не видно маленькой картинки «что загружено» — только имя/отсутствие UI.

## Сделать

Миниатюра (кадр из файла или poster): что за видео открыто. Обновлять при смене файла; по желанию — при scrub показывать кадр с позиции (если дёшево).

Не путать с основным канвасом паттерна: это превью **источника**, не dest.

## Готово

Рядом с контролами файла видно миниатюру загруженного видео.
